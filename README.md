# Video Manager

PyQt6を使用したデスクトップ動画管理アプリケーションです。

## モダンUI

- **デザイントークン方式のテーマシステム** (`theme.py`) - ダーク/ライトの全カラーを一元管理し、アプリ全体（ダイアログ含む）に統一適用
- **ヘッダーバー** - 丸型検索ボックス、セグメント式のグリッド/リスト切替、アイコンボタン（更新・タグ・統計）を1列に集約
- **サイドバー** - セクション見出し（SMART COLLECTIONS / PLAYLISTS / FOLDERS）とアイコン付き項目
- **動画カード** - 角丸サムネイル、再生時間バッジ、お気に入り★、視聴進捗バーをオーバーレイ表示
- **プレイヤー** - メディア向けのダーク固定コントロールバー（アプリテーマに依存しない）

## 機能

### 基本機能
- **複数フォルダ対応** - 複数のフォルダを登録して動画ライブラリを構築
- **サブフォルダ対応** - フォルダ追加時に再帰的スキャンが可能
- **サムネイル表示** - 動画のサムネイルを自動生成して表示
- **表示モード切替** - グリッド表示とリスト表示を切り替え可能
- **再生時間表示** - 各動画の再生時間を自動取得して表示
- **検索機能** - ファイル名でリアルタイム検索
- **高度な検索** - 再生時間、解像度、ファイルサイズで絞り込み
- **ソート機能** - 名前/再生時間/追加日時/お気に入りでソート
- **お気に入り** - 動画にスターを付けて素早くアクセス
- **タグ管理** - タグを事前登録し、動画ごとに複数のタグを割り当て可能
- **自動タグ付け** - ファイル名やフォルダ名から自動でタグを割り当て
- **タグフィルタリング** - タグで動画を絞り込み検索
- **ドラッグ＆ドロップ** - フォルダや動画ファイルをD&Dで追加

### 内蔵プレイヤー
- **内蔵動画プレイヤー** - アプリ内で直接動画を再生
- **視聴進捗保存** - 途中で止めた位置を自動保存
- **レジューム再生** - 前回の位置から再生を再開
- **シークバー** - 任意の位置にジャンプ
- **音量調整** - 音量スライダーとミュート機能
- **再生速度変更** - 0.25x〜2.0xの速度調整
- **A-Bリピート** - 指定区間をループ再生
- **スクリーンショット** - 再生中のフレームを画像として保存
- **字幕対応** - SRT/VTT/ASS/SSA字幕ファイルの読み込み

### プレイリスト
- **プレイリスト作成** - 動画をまとめて管理
- **プレイリストに追加** - 右クリックメニューから追加
- **順序変更** - プレイリスト内の動画を並び替え

### スマートコレクション
- **条件ベースの自動分類** - 再生時間、解像度、ファイルサイズ、追加日時で自動分類
- **例**: 「4K動画」「1時間以上」「最近追加」など

### 再生履歴・統計
- **再生履歴** - 最近再生した動画の履歴を表示
- **最近追加** - 最近ライブラリに追加した動画を表示
- **再生回数** - 各動画の再生回数を記録
- **統計ダッシュボード** - ライブラリの統計情報を表示
  - 総動画数、総再生時間、総容量
  - お気に入り数、タグ数、フォルダ数
  - 過去7日間の再生数

### データ管理
- **重複検出** - ファイルハッシュで重複動画を検出・管理
- **リンク切れチェック** - 存在しない動画ファイルを検出・削除
- **エクスポート/インポート** - ライブラリデータのバックアップ・復元

### 設定・カスタマイズ
- **テーマ切替** - ダークモード/ライトモードを選択
- **サムネイルサイズ調整** - グリッド表示のサムネイルサイズを変更
- **ウィンドウ状態保存** - ウィンドウサイズと位置を記憶

## 必要要件

- Python 3.10以上
- PyQt6
- PyQt6-Multimedia (内蔵プレイヤー用)
- OpenCV (opencv-python)

## インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd video_manager

# 依存パッケージをインストール
pip install -r video_manager/requirements.txt
```

## 使い方

### 起動

```bash
python run_video_manager.py
```

### 基本操作

| 操作 | 方法 |
|------|------|
| フォルダ追加 | File → Add Folder または左パネルの「+」ボタン |
| 表示モード切替 | ツールバーの「Grid View」/「List View」 |
| 動画再生 | 動画をダブルクリック または Enter |
| 検索 | 検索ボックスに入力（Ctrl+F でフォーカス） |
| 高度な検索 | Library → Advanced Search |
| ソート | Sort ドロップダウンで選択 |
| お気に入り追加 | 動画選択後「★」ボタン または F キー |
| タグ登録 | Tools → Manage Tags |
| 自動タグ付け | Tools → Auto-Tag Selected Video |
| スマートコレクション | Library → New Smart Collection |
| プレイリスト | Library → Manage Playlists |
| 重複検出 | Library → Find Duplicates |
| 設定 | File → Settings |

### キーボードショートカット

#### ライブラリ画面

| キー | 操作 |
|------|------|
| `Ctrl+F` | 検索ボックスにフォーカス |
| `Ctrl+Shift+F` | 高度な検索を開く |
| `Ctrl+O` | フォルダを追加 |
| `Ctrl+,` | 設定を開く |
| `Ctrl+1` | グリッド表示 |
| `Ctrl+2` | リスト表示 |
| `Enter` | 選択中の動画を再生 |
| `Delete` | 選択中の動画をライブラリから削除 |
| `F` | お気に入りのON/OFF切替 |
| `Escape` | 検索をクリア |

#### 内蔵プレイヤー

| キー | 操作 |
|------|------|
| `Space` | 再生/一時停止 |
| `←` | 5秒戻る |
| `→` | 5秒進む |
| `↑` | 音量を上げる |
| `↓` | 音量を下げる |
| `M` | ミュートON/OFF |
| `,` | 再生速度を下げる |
| `.` | 再生速度を上げる |
| `[` | A点を設定 |
| `]` | B点を設定 |
| `L` | A-Bリピート切替 |
| `S` | スクリーンショット |
| `Escape` | プレイヤーを閉じる |

### コンテキストメニュー

動画を右クリックすると以下の操作が可能です：

- **Play (External)** - 外部プレイヤーで再生
- **Play (Built-in Player)** - 内蔵プレイヤーで再生
- **Resume from...** - 前回の位置から再開
- **Add to Favorites / Remove from Favorites** - お気に入り切替
- **Add to Playlist** - プレイリストに追加
- **Open Containing Folder** - 動画のあるフォルダを開く
- **Remove from Library** - ライブラリから削除

フォルダを右クリック:

- **Rescan Folder** - フォルダを再スキャン
- **Rescan with Subfolders** - サブフォルダ含めて再スキャン
- **Remove Folder** - フォルダをライブラリから削除

## 対応動画形式

- MP4, AVI, MKV, MOV, WMV, FLV, WebM
- M4V, MPEG, MPG, 3GP, OGV

## 対応字幕形式

- SRT, VTT, ASS, SSA

## データ保存場所

アプリケーションデータは以下に保存されます：

```
~/.video_manager/
├── videos.db        # データベース（SQLite）
├── thumbnails/      # サムネイルキャッシュ
└── screenshots/     # スクリーンショット保存先
```

```
└── widgets/

    ├── video_item.py     # 動画表示ウィジェット
    ├── tag_widget.py     # タグ管理ウィジェット
    ├── video_player.py   # 内蔵ビデオプレイヤー
    ├── statistics_dialog.py  # 統計ダッシュボード
    └── dialogs.py        # 各種ダイアログ
```
