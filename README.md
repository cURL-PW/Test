# Video Manager

PyQt6を使用したデスクトップ動画管理アプリケーションです。

## 機能

### 基本機能
- **複数フォルダ対応** - 複数のフォルダを登録して動画ライブラリを構築
- **サブフォルダ対応** - フォルダ追加時に再帰的スキャンが可能
- **サムネイル表示** - 動画のサムネイルを自動生成して表示
- **表示モード切替** - グリッド表示とリスト表示を切り替え可能
- **再生時間表示** - 各動画の再生時間を自動取得して表示
- **検索機能** - ファイル名でリアルタイム検索
- **ソート機能** - 名前/再生時間/追加日時/お気に入りでソート
- **お気に入り** - 動画にスターを付けて素早くアクセス
- **タグ管理** - タグを事前登録し、動画ごとに複数のタグを割り当て可能
- **タグフィルタリング** - タグで動画を絞り込み検索
- **キーボードショートカット** - 効率的な操作が可能

### 内蔵プレイヤー
- **内蔵動画プレイヤー** - アプリ内で直接動画を再生
- **視聴進捗保存** - 途中で止めた位置を自動保存
- **レジューム再生** - 前回の位置から再生を再開
- **シークバー** - 任意の位置にジャンプ
- **音量調整** - 音量スライダーとミュート機能

### 再生履歴・統計
- **再生履歴** - 最近再生した動画の履歴を表示
- **再生回数** - 各動画の再生回数を記録
- **統計ダッシュボード** - ライブラリの統計情報を表示
  - 総動画数、総再生時間、総容量
  - お気に入り数、タグ数、フォルダ数
  - 過去7日間の再生数

### メタデータ・その他
- **メタデータ表示** - 解像度、ファイルサイズ、再生回数を表示
- **ドラッグ＆ドロップ** - フォルダや動画ファイルをD&Dで追加

## 必要要件

- Python 3.10以上
- PyQt6
- OpenCV (opencv-python)

## インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd video_manager

# 依存パッケージをインストール
pip install -r video_manager/requirements.txt
```

## 使い方

### 起動

```bash
python run_video_manager.py
```

### 基本操作

| 操作 | 方法 |
|------|------|
| フォルダ追加 | 左パネルの「+」ボタンをクリック |
| サブフォルダ含む | フォルダ追加時に「Include subfolders」にチェック |
| フォルダ削除 | フォルダを右クリック → 「Remove Folder」 |
| 表示モード切替 | ツールバーの「Grid View」/「List View」 |
| 動画再生 | 動画をダブルクリック または Enter |
| 検索 | 検索ボックスに入力（Ctrl+F でフォーカス） |
| ソート | Sort ドロップダウンで選択 |
| お気に入り追加 | 動画選択後「★」ボタン または F キー |
| お気に入り一覧 | 左パネルの「★ Favorites」をクリック |
| タグ登録 | ツールバーの「Manage Tags」からタグを事前登録 |
| タグ割り当て | 動画選択後、「+ Add Tags」から登録済みタグを選択 |
| タグ解除 | 動画のタグ横の「x」ボタンをクリック |
| タグで絞り込み | 左パネルのタグをクリック（複数選択可） |
| 絞り込み解除 | 「Clear」ボタンをクリック |

### キーボードショートカット

#### ライブラリ画面

| キー | 操作 |
|------|------|
| `Ctrl+F` | 検索ボックスにフォーカス |
| `Enter` | 選択中の動画を再生 |
| `Delete` | 選択中の動画をライブラリから削除 |
| `F` | お気に入りのON/OFF切替 |
| `Escape` | 検索をクリア |

#### 内蔵プレイヤー

| キー | 操作 |
|------|------|
| `Space` | 再生/一時停止 |
| `←` | 5秒戻る |
| `→` | 5秒進む |
| `↑` | 音量を上げる |
| `↓` | 音量を下げる |
| `M` | ミュートON/OFF |
| `Escape` | プレイヤーを閉じる |

### コンテキストメニュー

動画を右クリックすると以下の操作が可能です：

- **Play** - デフォルトプレイヤーで再生
- **Add to Favorites / Remove from Favorites** - お気に入り切替
- **Open Containing Folder** - 動画のあるフォルダを開く
- **Remove from Library** - ライブラリから削除（ファイルは削除されません）

フォルダを右クリック:

- **Rescan Folder** - フォルダを再スキャン
- **Rescan with Subfolders** - サブフォルダ含めて再スキャン
- **Remove Folder** - フォルダをライブラリから削除

## 対応動画形式

- MP4, AVI, MKV, MOV, WMV, FLV, WebM
- M4V, MPEG, MPG, 3GP, OGV

## データ保存場所

アプリケーションデータは以下に保存されます：

```
~/.video_manager/
├── videos.db        # データベース（SQLite）
└── thumbnails/      # サムネイルキャッシュ
```
